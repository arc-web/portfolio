## Public-Use Boundary

Raw transcript chunks stay out of GitHub because they can include:

- client names that need approval;
- account reset walkthroughs;
- private operational language;
- source paths from the local machine;
- content that should be generalized before publication.

Only summary counts, generalized patterns, approved claims, and anonymized
lessons belong in the public repo.
