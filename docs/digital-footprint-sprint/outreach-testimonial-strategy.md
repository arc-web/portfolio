# Outreach And Testimonial Strategy

Date checked: 2026-07-06

Purpose: turn past work into fresh public proof through specific, relationship-aware
requests instead of generic testimonial blasts.

## Workbook Queue

The local workbook sheet `Outreach Strategy Queue` contains 32 outreach rows.
Each row tracks:

- source group;
- recipient group;
- relationship context;
- requested proof asset;
- outreach channel;
- draft message;
- follow-up timing;
- proof slot filled;
- public-use boundary;
- owner next action;
- approval gate.

## Priority Groups

1. LinkedIn personal:
   - refresh recommendations from warm existing recommenders;
   - request skill endorsements from people who directly saw the work;
   - ask for warm introductions to executive teams, founder groups, and event organizers.
2. AI Brain Builders:
   - request partner and attendee testimonials from workshop sources;
   - collect permission for event photos, clips, venue names, and prototype references;
   - capture one thing built, one thing learned, and permission status.
3. Advertising Report Card:
   - request client testimonials for reporting, tracking, paid media, strategy, and website work;
   - request case-study approval or anonymized proof paths;
   - review ARC YouTube audit examples before naming clients or metrics.
4. Brand-specific proof:
   - Failure Trucks logistics proof and operator introductions;
   - Therapy PC proof discovery before healthcare-related claims;
   - StackPack and community proof only through fresh opt-in testimonials.
5. Prospect outreach:
   - use proof-led introductions only after the public proof page and approved assets are live.

## Draft Message Types

| Message | Use |
|---|---|
| LinkedIn recommendation refresh | Ask existing professional contacts for an updated recommendation focused on practical outcomes |
| LinkedIn skill endorsement ask | Ask contacts to endorse only skills they have directly seen |
| Speaking introduction ask | Ask for introductions to executive teams, founder groups, or event organizers |
| Workshop attendee testimonial ask | Ask what they built, what they learned, and what can be public |
| Event media permission ask | Confirm who owns photos/clips and whether faces, venue names, or screens can be used |
| ARC client testimonial ask | Ask for 1-2 sentences about reporting, tracking, paid media, strategy, or web work |
| ARC case-study permission ask | Ask for named case study, anonymized case study, or testimonial-only approval |
| Video testimonial prompt | 15-30 second phone clip answering what changed or why they recommend the work |

## Approval Rule Before Sending

Before any outreach is sent, document:

- recipient;
- channel;
- exact message text;
- proof referenced;
- requested public-use right;
- what is not approved by the send.

Sending a request does not approve public quote reuse, media reuse, profile edits,
website edits, posting, publishing, uploading, paid tool use, or prospect blasts.

## Public-Use Rule

No private email, transcript, attendee name, client metric, company logo, face,
voice, video clip, third-party client name, or partner claim is public until the
exact public use is approved.
